# Example Prompt: High-Performance SaaS / Product Landing Page

Use this prompt to build a fast-loading landing page via the Elementor MCP.

```text
Build a high-performance landing page in draft mode using the Elementor MCP for a modern SaaS product named "CloudPulse".

Structure requirements:
1. Hero Section (Above-the-fold):
   - Two-column Flexbox Container.
   - Left: Main H1 heading with clear value proposition, 2-line description paragraph, and a primary CTA button ("Start Free Trial") with high contrast.
   - Right: Single static product preview image inside a container with 16:9 aspect ratio and high priority loading.
   - Strict rule: No carousels, no video background, no empty spacers.

2. Social Proof / Metrics Section:
   - Single full-width container with a 4-column CSS grid.
   - Each column displays a key metric (e.g., "99.9% Uptime", "10k+ Users", "4.9/5 Rating", "< 100ms Latency").
   - Use clean typography with 600 weight and muted subtext.

3. Features Grid:
   - H2 heading ("Engineered for Unmatched Speed").
   - 3-column container grid featuring Icon Boxes with inline SVGs, short concise headings (H3), and brief descriptions.

4. Testimonial Section:
   - 2-column container with 2 customer quote cards.
   - Each card includes customer avatar (1:1 aspect ratio, 64x64px), customer name, role, and quote text.

5. Final CTA Section:
   - Centered container with high-contrast background.
   - H2 heading, short paragraph, and primary CTA button linked to sign-up.

Ensure all layout containers have maximum 2 levels of nesting, typography adheres to standard fonts, and image elements include descriptive alt text.
```
